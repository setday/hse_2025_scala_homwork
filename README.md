## Задание

В задании от вас потербуется реализовать односвязный список в двух стилях: Объекно-ориентированном и функциональном. В идеале обе реализации должны работать в for expressions и for loops

### Задание 1

Реализовать односвязный список в более привычном объектно-ориентированном стиле чтобы он соотетствовал trait-у [List](./src/main/scala/ru/hse/aml/oop/List.scala)и реализовывал все методы, требуемые для использования в for.

Можете использовать var и любые знакомые вам техники из более привычных языков. Главное не используйте готовые коллекции из стандартной библиотеки

### Задание 2

Реализовать тот же односвязный список, но при помощи enum-а описанного в [файле](./src/main/scala/ru/hse/aml/FP/FPList.scala).
Также от вас требуется описать класс типов Forable объявленный в [файле с классами типов](./src/main/scala/ru/hse/aml/FP/Typeclasses.scala) чтобы реализации этого класса типов было достаточно для использования в цикле for

Вам потребуется реализовать 2 класса типов, один для базовых функций List-а и Forable.

### Задание 3

Протестируйте своё решение при помощи scalatest. Можете использовать любые возможности scalatest-а, не обязательно ограничивать себя данным классом для тестов.

Какого-то невероятного покрытия не требуется, но попробуйте описать все базовые случаи использования

Бонусный балл, если будет желание разобраться со scalacheck и написать property based тесты
